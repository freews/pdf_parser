#### 5.2.12.1.14.2.12 Telemetry Log Create Event (Event Type 0Ch)

A Telemetry Log Create event may be created if the controller determines that a Telemetry Host-Initiated log page (refer to section 5.2.12.1.8) or that a Telemetry Controller-Initiated log page (refer to section 5.2.12.1.9) has been generated.

The Telemetry Log Create Event shall set the Persistent Event Log Event Header:

- Event Type field to 0Ch; and
- Event Type Revision Field to 01h.
