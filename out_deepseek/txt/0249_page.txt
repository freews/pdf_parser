### 5.2.12.1.8 Telemetry Host-Initiated (Log Page Identifier 07h)

This log page consists of a header (i.e., bytes 511:0 of the log page) describing the log and zero or more Telemetry Data Blocks (refer to section 8.1.29). The header shall always be available even if there is no Telemetry Host-Initiated Data available. All Telemetry Data Blocks are 512 bytes in size. The controller shall initiate a capture of internal controller-scoped or NVM subsystem-scoped state to this log page if the controller processes a Get Log Page command for this log with the Create Telemetry Host-Initiated Data bit set to ‘1’ in the Log Specific Parameter field. The scope of the saved state is determined by the value in the Telemetry Host-Initiated Scope field. If the host specifies a Log Page Offset Lower value that is not a multiple of 512 bytes in the Get Log Page command for this log page, then the controller shall abort the command with a status code of Invalid Field in Command.
