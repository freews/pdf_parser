#### 5.4.3.1 Command Completion

Upon completion of the Cross-Controller Reset command, the controller posts a CQE to the Admin Completion Queue indicating the status for the Cross-Controller Reset command.

If the command completes successfully, Dword 0 of the CQE indicates information about the Cross-Controller Reset operation as shown in Figure 527.

### Figure 527: Cross-Controller Reset Command – Completion Queue Entry Dword 0

| Bits | Description |
|------|-------------|
| 31:03 | Reserved |
| 02 | Controller Level Reset Initiated (CLRI): This bit has the same definition as the Controller Level Reset Initiated bit defined in Figure 305. If the value of the IRS bit is set to ‘0’, the value of this bit is undefined. |
| 01 | Validated (V): This bit has the same definition as the Validated bit defined in Figure 305. If the value of the IRS bit is set to ‘0’, the value of this bit is undefined. |
| 00 | Immediate Reset Successful (IRS): If this bit is set to ‘1’, then: |
|      | • the Cross-Controller Reset operation completed successfully as described in section 8.3.3; |
|      | • the Source Controller does not report a Cross-Controller Reset Completed asynchronous event (refer to Figure 154) for the Cross-Controller Reset operation caused to be initiated by this command; and |
|      | • the Source controller does not add an entry for the Cross-Controller Reset operation to the Cross-Controller Reset log page. |
|      | If this bit is cleared to ‘0’, then the Cross-Controller Reset operation was not completed successfully before this CQE was posted. |

If the value of the ICID field in the Cross-Controller Reset command is the same as the controller ID of the Source Controller, the Source Controller shall abort the command with a status code of Invalid Field in Command. If:

- the value of the ICID field in the Cross-Controller Reset command is the same as the value of the ICID field in a pre-existing entry in the Cross-Controller Reset log page; and
- the Cross-Controller Reset Status (CCRS) field in that entry is set to In Progress,

the controller shall abort the command with a status code of Cross-Controller Reset in Progress.
