#### 5.2.6.1 Command Completion  

<|ref|>text<|/ref|><|det|>[[114, 356, 883, 401]]<|/det|>
When the command is completed, the controller posts a completion queue entry to the Admin Completion Queue indicating the status for the command. Command specific status values that may be returned are dependent on the Directive Type, refer to section 8.1.9.  

<|ref|>title<|/ref|><|det|>[[114, 409, 372, 425]]<|/det|>
#### 5.2.7 Directive Send command  

<|ref|>text<|/ref|><|det|>[[114, 434, 883, 464]]<|/det|>
The Directive Send command transfers a data buffer that is dependent on the Directive Type to the controller. Refer to section 8.1.9.  

<|ref|>text<|/ref|><|det|>[[114, 471, 883, 515]]<|/det|>
The Directive Send command uses the Data Pointer, Command Dword 10, and Command Dword 11 fields. Command Dword 12 and Command Dword 13 may be used based on the Directive Type field and the Directive Operation field. All other command specific fields are reserved.
