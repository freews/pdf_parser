#### 4.2.3.2 Command Specific Status Definition  

<|ref|>text<|/ref|><|det|>[[115, 822, 883, 881]]<|/det|>
Completion queue entries with a Status Code Type (SCT) of Command Specific Errors indicate an error that is specific to a particular command opcode. Status codes of 00h to 7Fh are for Admin command errors (refer to Figure 103). Status codes of 80h to BFh are specific to the selected I/O command sets (refer to Figure 104).
