<|ref|>text<|/ref|><|det|>[[142, 91, 883, 120]]<|/det|>
- while the CSTS.SHST field is set to 10b (i.e., shutdown processing complete) in all controllers in the NVM subsystem.  

<|ref|>text<|/ref|><|det|>[[115, 127, 883, 171]]<|/det|>
A set of interval power measurements may be contiguous or non- contiguous in time. A set of interval power measurements is contiguous if they are from a continuous period of time without any gaps. Examples of actions that are able to cause a set of interval power measurements to be non- contiguous include:  

<|ref|>text<|/ref|><|det|>[[143, 178, 883, 255]]<|/det|>
- removing power from the NVM subsystem (i.e., a power cycle);- entering a non-operational power state;- initiating an NVM Subsystem Reset; and- the CSTS.SHST field becoming set to 10b (i.e., shutdown processing complete) in all controllers in the NVM subsystem.
