<|ref|>text<|/ref|><|det|>[[115, 88, 753, 106]]<|/det|>
The host allocates the Media Units in a domain to Endurance Groups and NVM Sets by:  

<|ref|>text<|/ref|><|det|>[[143, 110, 883, 172]]<|/det|>
1) reading the Supported Capacity Configuration List log page (refer to Figure 261) and selecting the desired configuration; and2) issuing a Capacity Management command specifying the Select Capacity Configuration operation and the Capacity Configuration Identifier of the desired configuration.  

<|ref|>text<|/ref|><|det|>[[115, 176, 883, 222]]<|/det|>
Following successful completion of the command, each Media Unit is allocated to one Endurance Group and to one NVM Set. The resulting configuration of Media Units is reported by the Media Unit Status log page (refer to section 5.2.12.1.16).  

<|ref|>title<|/ref|><|det|>[[115, 229, 429, 246]]<|/det|>
#### 8.1.4.3 Variable Capacity Management  

<|ref|>text<|/ref|><|det|>[[115, 253, 883, 286]]<|/det|>
Variable Capacity Management allows the dynamic creation and deletion of Endurance Groups and NVM Sets.  

<|ref|>text<|/ref|><|det|>[[115, 290, 518, 308]]<|/det|>
A controller supporting Variable Capacity Management:  

<|ref|>text<|/ref|><|det|>[[143, 312, 883, 457]]<|/det|>
a) may support the Media Unit Status log page; 
b) shall support Endurance Groups; 
c) may support NVM Sets; 
d) shall set the Variable Capacity Management bit to '1' in the CTRATT field of the Identify Controller data structure (refer to Figure 328); 
e) shall support the Create Endurance Group operation of the Capacity Management command; 
f) may support the Delete Endurance Group operation of the Capacity Management command; and 
g) if NVM Sets are supported:  

<|ref|>text<|/ref|><|det|>[[200, 436, 883, 512]]<|/det|>
a. shall support the Create NVM Set operation of the Capacity Management command; 
b. shall report non-zero values in the Total Endurance Group Capacity field and the Unallocated Endurance Group Capacity field in the Endurance Group Information log page (refer to Figure 222); and 
c. may support the Delete NVM Set operation of the Capacity Management command.  

<|ref|>text<|/ref|><|det|>[[115, 516, 883, 563]]<|/det|>
If a controller supports the Delete Endurance Group operation of the Capacity Management command, then it shall set the Delete Endurance Group bit to '1' in the CTRATT field of the Identify Controller data structure.  

<|ref|>text<|/ref|><|det|>[[115, 567, 883, 600]]<|/det|>
If a controller supports the Delete NVM Set operation of the Capacity Management command, then it shall set the Delete NVM Set bit to '1' in the CTRATT field of the Identify Controller data structure.  

<|ref|>text<|/ref|><|det|>[[115, 605, 536, 622]]<|/det|>
A typical sequence of operations for allocating capacity is:  

<|ref|>text<|/ref|><|det|>[[143, 626, 829, 687]]<|/det|>
1) determine the available capacities in each domain (refer to section 3.2.5); 
2) create Endurance Group with desired capacity (refer to section 5.2.3); 
3) create NVM Set with desired capacity in the Endurance Group (refer to section 5.2.3); and 
4) create namespace with desired capacity in the NVM Set (refer to section 5.2.21).  

<|ref|>text<|/ref|><|det|>[[115, 692, 555, 709]]<|/det|>
A typical sequence of operations for deallocating capacity is:  

<|ref|>text<|/ref|><|det|>[[143, 713, 771, 760]]<|/det|>
1) delete namespace that contains formatted storage, if any, (refer to section 5.2.21); 
2) delete NVM Set, if any, (refer to section 5.2.30); and 
3) delete Endurance Group (refer to section 5.2.3).  

<|ref|>text<|/ref|><|det|>[[115, 764, 883, 812]]<|/det|>
If there is insufficient unallocated capacity in an Endurance Group for the controller to create an NVM Set, then the host can delete one or more NVM Sets in that Endurance Group and create the new NVM Set using some or all of the available capacity.  

<|ref|>text<|/ref|><|det|>[[115, 816, 883, 863]]<|/det|>
If there is insufficient unallocated capacity in a domain for the controller to create an Endurance Group, then the host can delete one or more Endurance Groups in that domain and create a new Endurance Group using some or all of the available capacity.
