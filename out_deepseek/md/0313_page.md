<|ref|>text<|/ref|><|det|>[[114, 90, 883, 134]]<|/det|>
This FDP event indicates that the controller modified a Reclaim Unit Handle to reference a different Reclaim Unit where that modification was not due to any host action (e.g., a write command that has a size greater than the remaining capacity of the initial Reclaim Unit being written).  

<|ref|>title<|/ref|><|det|>[[114, 148, 575, 164]]<|/det|>
#### 5.2.12.1.33 Power Measurement (Log Page Identifier 25h)  

<|ref|>text<|/ref|><|det|>[[114, 173, 883, 203]]<|/det|>
The Power Measurement log page (refer to Figure 297) is used for the reporting of logged interval power measurements for the Power Measurement capability, including:  

<|ref|>text<|/ref|><|det|>[[143, 210, 532, 256]]<|/det|>
the average of the interval power measurements; the maximum interval power measurement; and a histogram of the interval power measurements.  

<|ref|>text<|/ref|><|det|>[[114, 263, 705, 279]]<|/det|>
The information in this log page shall be retained across power cycles and resets.  

<|ref|>text<|/ref|><|det|>[[116, 285, 452, 301]]<|/det|>
This log page is global to the NVM subsystem.  

<|ref|>text<|/ref|><|det|>[[114, 307, 598, 322]]<|/det|>
Refer to section 8.1.19.1 for the usage of this log page by the host.  

<|ref|>text<|/ref|><|det|>[[114, 329, 883, 374]]<|/det|>
The Power Histogram Descriptor is defined in Figure 298. In this log page, the Power Histogram Descriptors shall be listed in ascending order based on the power indicated by the Power Histogram Bin Lower Threshold (PHBLT) field.  

<|ref|>text<|/ref|><|det|>[[114, 381, 133, 394]]<|/det|>
If:  

<|ref|>text<|/ref|><|det|>[[143, 403, 883, 450]]<|/det|>
the Power Measurement Count (PMC) field is set to a non- zero value at the time this log page is read; and the Number of Power Histogram Descriptors Supported (NPHDS) field is set to a non- zero value,  

<|ref|>text<|/ref|><|det|>[[114, 457, 149, 470]]<|/det|>
then  

<|ref|>text<|/ref|><|det|>[[143, 478, 883, 583]]<|/det|>
the first Power Histogram Descriptor (i.e., Power Histogram Descriptor 0) shall have the Power Histogram Bin Lower Threshold (PHBLT) field set to 0 Watts; the last Power Histogram Descriptor (i.e., Power Histogram Descriptor NPHD- 1) shall contain the highest power in the PHBLT field with a non- zero value in the Power Histogram Bin Count (PHBC) field; and there shall be no gaps in the power ranges in the set of Power Histogram Descriptors returned (i.e. Power Histogram Descriptors with non- zero values in PHBC field are not packed together).  

<|ref|>text<|/ref|><|det|>[[114, 589, 883, 621]]<|/det|>
If the Power Measurement Count (PMC) field is cleared to Oh at the time this log page is read, then the Number of Power Histogram Descriptors (NPHD) field shall be cleared to Oh.
