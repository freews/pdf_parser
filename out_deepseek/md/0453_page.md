<|ref|>title<|/ref|><|det|>[[114, 517, 494, 533]]<|/det|>
#### 5.2.26.1.25 Power Limit (Feature Identifier 23h)  

<|ref|>text<|/ref|><|det|>[[114, 541, 882, 629]]<|/det|>
This Feature is used by the host to configure the Power Limit capability (refer to section 8.1.18.6) that enables a host to limit the set of available NVMe power states for a controller. The power limit, specified in the Power Limit Value (PLV) attribute, is the maximum power that is able to be consumed by the NVM subsystem if all controllers in the NVM subsystem are subject to the same power limit. Setting a power limit modifies the reported set of power state descriptors that are part of the Identify Controller data structure (refer to section 8.1.18.6).  

<|ref|>text<|/ref|><|det|>[[114, 636, 882, 681]]<|/det|>
The attributes for this Feature are specified in Command Dword 13 (refer to Figure 452). Upon successful completion of a Set Features command for this Feature, the power limit shall function as described in section 8.1.18.6.  

<|ref|>text<|/ref|><|det|>[[115, 688, 343, 703]]<|/det|>
This Feature shall be saveable.  

<|ref|>text<|/ref|><|det|>[[114, 710, 882, 740]]<|/det|>
If a Get Features command is submitted for this Feature, then the attributes described in Figure 452 are returned in Dword 0 of the completion queue entry for that command.
