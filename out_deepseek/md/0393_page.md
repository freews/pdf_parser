#### 5.2.13.2.20 I/O Command Set Independent Identify Namespace data structure for an Allocated Namespace ID (CNS 1Fh)  

<|ref|>text<|/ref|><|det|>[[114, 481, 883, 527]]<|/det|>
An I/O Command Set Independent Identify Namespace data structure (refer to section 5.2.13.2.8) is returned to the host for the namespace specified in the Namespace Identifier (NSID) field if it is an allocated NSID. If the specified NSID is an unallocated NSID, then the controller returns a zero filled data structure.  

<|ref|>text<|/ref|><|det|>[[114, 533, 883, 579]]<|/det|>
If the specified NSID is an invalid NSID, then the controller shall abort the command with a status code of Invalid Namespace or Format. If the NSID field is set to FFFFFFFFh, then the controller shall abort the command with a status code of Invalid Namespace or Format.

#### 5.2.13.2.21 Supported Controller State Formats (CNS 20h)  

<|ref|>text<|/ref|><|det|>[[114, 611, 883, 656]]<|/det|>
A Supported Controller State Formats data structure (refer to Figure 345) is returned to the host identifying the supported NVMe Controller State data structures (refer to Figure 346) and a list of UUIDs that identifies the vendor specific controller state information.  

<|ref|>text<|/ref|><|det|>[[114, 662, 883, 693]]<|/det|>
A host uses an index into each list to identify the format and information returned by a Migration Receive command specifying the Get Controller State management operation (refer to section 5.2.16.1.1).  

<|ref|>text<|/ref|><|det|>[[114, 699, 883, 744]]<|/det|>
A host uses an index into each list to identify the format and information contained in a Migration Send command specifying the Set Controller State management operation of the Migration Send command (refer to section 5.2.17.1.3).
