<|ref|>text<|/ref|><|det|>[[114, 89, 883, 150]]<|/det|>
**DH Value (DHV):** Diffie-Hellman exponential. If the DH Value Length is cleared to 0h, this field is not present. The DH Value shall be set to the value of g\(^{2}\) mod p, where y is a random number selected by the host that shall be at least 256 bits long (refer to section 8.3.5.5.7) and p and g shall have the values indicated in Figure 799, based on the selected DH group identifier.

Upon receiving a DH-HMAC-CHAP_Reply message, if:

<|ref|>text<|/ref|><|det|>[[143, 179, 883, 208]]<|/det|>
· the Hash Length (HL) does not match the value specified in Figure 798 for the selected hash function;

<|ref|>text<|/ref|><|det|>[[143, 208, 721, 222]]<|/det|>
· DHgID is non-zero and the DH Value Length (DHVLEN) is cleared to 0h; or

<|ref|>text<|/ref|><|det|>[[143, 224, 600, 238]]<|/det|>
· DHgID is non-zero and the DH Value (DHV) is 0, 1, or p-1;

<|ref|>text<|/ref|><|det|>[[143, 247, 322, 259]]<|/det|>
then the controller shall:

<|ref|>text<|/ref|><|det|>[[143, 269, 883, 298]]<|/det|>
· reply with an AUTH_Failure1 message having reason code 'Authentication failure' and reason code explanation 'Incorrect payload'; and

<|ref|>text<|/ref|><|det|>[[143, 300, 514, 312]]<|/det|>
· disconnect the NVMe over Fabrics connection.

<|ref|>text<|/ref|><|det|>[[114, 322, 340, 334]]<|/det|>
In addition, the controller shall:

<|ref|>text<|/ref|><|det|>[[143, 344, 883, 372]]<|/det|>
· check the challenge value \(C_{2}\) , if the Challenge Valid field is set to 01h, to verify it is different from the challenge value \(C_{1}\) the controller previously sent. If \(C_{2}\) is equal to \(C_{1}\) , the controller shall:

<|ref|>text<|/ref|><|det|>[[203, 380, 883, 409]]<|/det|>
O reply with an AUTH_Failure1 message having reason code 'Authentication failure' and reason code explanation 'Authentication failed'; and

<|ref|>text<|/ref|><|det|>[[203, 411, 574, 423]]<|/det|>
O disconnect the NVMe over Fabrics connection;

<|ref|>text<|/ref|><|det|>[[173, 433, 207, 444]]<|/det|>
and

<|ref|>text<|/ref|><|det|>[[143, 455, 883, 483]]<|/det|>
· verify the response value \(R_{1}\) using the negotiated hash function. If verification of the response value \(R_{1}\) does not succeed, the controller shall:

<|ref|>text<|/ref|><|det|>[[203, 491, 883, 520]]<|/det|>
O reply with an AUTH_Failure1 message having reason code 'Authentication failure' and reason code explanation 'Authentication failed'; and

<|ref|>text<|/ref|><|det|>[[203, 522, 574, 533]]<|/det|>
O disconnect the NVMe over Fabrics connection.

<|ref|>text<|/ref|><|det|>[[114, 543, 883, 571]]<|/det|>
