#### 5.2.12.1.22 Rotational Media Information Log (Log Page Identifier 16h)  

<|ref|>text<|/ref|><|det|>[[114, 484, 883, 514]]<|/det|>
This log page provides rotational media information (refer to section 8.1.25) for Endurance Groups that store data on rotational media. The information provided is retained across power cycles and resets.  

<|ref|>text<|/ref|><|det|>[[114, 520, 883, 551]]<|/det|>
The Endurance Group Identifier is specified in the Log Specific Identifier field in Command Dword 11 of the Get Log Page command as defined in Figure 221.  

<|ref|>text<|/ref|><|det|>[[114, 556, 883, 587]]<|/det|>
If the NVM subsystem does not contain any Endurance Groups that store data on rotational media, then the Rotational Media Information Log should not be supported.
