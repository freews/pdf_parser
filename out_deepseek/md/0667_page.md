## Transition Unrestricted Processing:Idle:  

<|ref|>text<|/ref|><|det|>[[115, 415, 260, 430]]<|/det|>
The controller shall:  

<|ref|>text<|/ref|><|det|>[[144, 436, 517, 452]]<|/det|>
a) if the sanitization target is the NVM subsystem:  

<|ref|>text<|/ref|><|det|>[[202, 458, 626, 474]]<|/det|>
o if the Sanitize Namespace command is not supported:  

<|ref|>text<|/ref|><|det|>[[262, 480, 882, 542]]<|/det|>
i. set the Global Data Erased (GDE) bit to '1' in the Sanitize Status log page for the NVM subsystem; andii. set the Sanitize State (SANS) field to Oh (i.e., Idle state) in the Sanitize Status log page for the NVM subsystem;  

<|ref|>text<|/ref|><|det|>[[231, 549, 250, 561]]<|/det|>
or  

<|ref|>text<|/ref|><|det|>[[202, 568, 600, 584]]<|/det|>
o if the Sanitize Namespace command is supported:  

<|ref|>text<|/ref|><|det|>[[262, 590, 882, 664]]<|/det|>
i. set the Global Data Erased (GDE) bit to '1' in every Sanitize Status log pageii. set the Namespace Data Erased (NDE) bit to '1' in the Sanitize Status log page for each namespace that exists in the NVM subsystem; andiii. set the SANS field to Oh (i.e., Idle state) in the Sanitize Status log page for the NVM subsystem and each namespace that exists in the NVM subsystem;  

<|ref|>text<|/ref|><|det|>[[144, 670, 467, 686]]<|/det|>
b) if the sanitization target is a namespace:  

<|ref|>text<|/ref|><|det|>[[202, 692, 882, 756]]<|/det|>
o set the Namespace Data Erased (NDE) bit to '1' in the Sanitize Status log page for that namespace; ando set the SANS field to Oh (i.e., Idle state) in the Sanitize Status log page for that namespace; and  

<|ref|>text<|/ref|><|det|>[[144, 764, 882, 795]]<|/det|>
c) report the Sanitize Operation Completed asynchronous event or the Sanitize Operation Completed With Unexpected Deallocation asynchronous event as described in section 8.1.26.1.

## Transition Unrestricted Processing:Unrestricted Failure:  

<|ref|>text<|/ref|><|det|>[[115, 825, 260, 840]]<|/det|>
The controller shall:  

<|ref|>text<|/ref|><|det|>[[142, 846, 882, 907]]<|/det|>
a) set the FAILS field to 3h in the Sanitize Status log page for the sanitization target (i.e., Unrestricted Processing state); andb) report the Sanitize Operation Completed asynchronous event or the Sanitize Operation Completed With Unexpected Deallocation asynchronous event as described in section 8.1.26.1.
