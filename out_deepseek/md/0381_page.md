#### 5.2.13.2.2 Active Namespace ID list (CNS 02h)  

<|ref|>text<|/ref|><|det|>[[114, 382, 882, 471]]<|/det|>
A list of 1,024 namespace IDs is returned to the host containing active NSIDs in increasing order that are greater than the value specified in the Namespace Identifier (NSID) field of the command. The controller shall abort the command with a status code of Invalid Namespace or Format if the NSID field is set to FFFFFFFEh or FFFFFFFFh. The NSID field may be cleared to 0h to retrieve a Namespace List including the namespace starting with NSID of 1h. The data structure returned is a Namespace List (refer to section 4.6.2).  

<|ref|>title<|/ref|><|det|>[[115, 479, 615, 496]]<|/det|>
#### 5.2.13.2.3 Namespace Identification Descriptor list (CNS 03h)  

<|ref|>text<|/ref|><|det|>[[114, 504, 882, 636]]<|/det|>
A list of Namespace Identification Descriptor structures (refer to Figure 331) is returned to the host for the specified namespace if the value in the Namespace Identifier (NSID) field is an active NSID. The controller shall abort the command with a status code of Invalid Namespace or Format if the NSID field is set to FFFFFFFEh or is set to FFFFFFFFh. Namespace Identification Descriptor structures consist of one or more Namespace Identifiers (NID) of various types as indicated by the Namespace Identifier Type (NIDT) field in each descriptor. Each NID is assigned to a namespace at namespace creation and remains fixed throughout the life of that namespace. If the NSID field does not specify an active NSID, then refer to section 3.2.1.5 for the status code to return. Textual representations related to Boot of NIDs may be found in the NVM Express Boot Specification.  

<|ref|>text<|/ref|><|det|>[[115, 643, 879, 674]]<|/det|>
The contents of the Namespace Identification Descriptor list is preserved across namespace and controller operations (e.g., Controller Level Reset, namespace format, etc.).  

<|ref|>text<|/ref|><|det|>[[114, 679, 882, 754]]<|/det|>
The controller may return any number of variable length Namespace Identification Descriptor structures that fit into the 4,096 byte Identify payload. All remaining bytes after the Namespace Identification Descriptor structures should be cleared to 0h, and the host shall interpret a Namespace Identifier Descriptor Length (NIDL) value of 0h as the end of the list. The host should ignore any Namespace Identification Descriptor with a Namespace Identifier Type not supported by the host.  

<|ref|>text<|/ref|><|det|>[[115, 760, 879, 790]]<|/det|>
A controller shall not return multiple Namespace Identification Descriptors with the same Namespace Identifier Type (NIDT). A controller shall return:  

<|ref|>text<|/ref|><|det|>[[143, 797, 882, 858]]<|/det|>
- at least one Namespace Identification Descriptor identifying the namespace (i.e., NIDT field set to 1h, 2h, or 3h); and- A Namespace Identification Descriptor identifying the I/O Command Set (i.e., NIDT field set to 4h) if the CAP.CSS.IOCSS bit is set to '1'.
