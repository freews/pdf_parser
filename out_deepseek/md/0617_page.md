The PSD data structure for a prohibited power state is removed from the Identify Controller data structure. If a prohibited power state becomes enabled (e.g., as a consequence of removing a power limit), then the PSD data structure for that power state is restored. In both cases, the power states that are enabled for use are renumbered so that the power states are contiguously numbered starting with zero with the maximum power of each subsequent power state being less than or equal to the maximum power of the previous power state, as described in section 8.1.18.

Power state entries in the Autonomous Power State Transition table are renumbered as a result of the Power Limit feature changing the PSD table. The Autonomous Power State Transition table is modified to remove entries for prohibited power states and the Idle Transition Power State field in each remaining entry to indicate the new number of that power state that resulted from modification of the Power Limit feature.

This feature is used by a host to:
