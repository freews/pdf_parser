# 5.2.5 Device Self-test command

<|ref|>text<|/ref|><|det|>[[114, 531, 883, 558]]<|/det|>
The Device Self-test command is used to start a device self-test operation or abort a device self-test operation (refer to section 8.1.8). The Device Self-test command is used specifically to:

<|ref|>text<|/ref|><|det|>[[143, 568, 456, 580]]<|/det|>
a) start a short device self-test operation;

<|ref|>text<|/ref|><|det|>[[143, 583, 494, 594]]<|/det|>
b) start an extended device self-test operation;

<|ref|>text<|/ref|><|det|>[[143, 597, 457, 609]]<|/det|>
c) start a Host-Initiated Refresh operation;

<|ref|>text<|/ref|><|det|>[[143, 611, 550, 623]]<|/det|>
d) start a vendor specific device self-test operation; or

<|ref|>text<|/ref|><|det|>[[143, 625, 555, 637]]<|/det|>
e) abort a device self-test operation already in process.

<|ref|>text<|/ref|><|det|>[[114, 647, 584, 659]]<|/det|>
A Host-Initiated Refresh operation is a device self-test operation.

<|ref|>text<|/ref|><|det|>[[114, 670, 883, 726]]<|/det|>
The device self-test operation is performed by the controller that the Device Self-test command was submitted to. The Namespace Identifier field controls which namespaces are included in the device self-test operation as specified in Figure 174. For a Host-Initiated Refresh operation, the Namespace Identifier field shall be ignored by the controller.
