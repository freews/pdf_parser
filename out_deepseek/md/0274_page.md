#### 5.2.12.1.14.2.6 Change Namespace Event (Event Type 06h)  

<|ref|>text<|/ref|><|det|>[[115, 550, 883, 626]]<|/det|>
The Changed Namespace Event (refer to Figure 244) persists the host parameters used for successful Namespace Management commands. This event type is specific to namespaces that are associated with I/O Command Sets that specify logical blocks (e.g., the NVM Command Set and the Zoned Namespace Command Set). The event contains a Persistent Event Log Event header and the Change Namespace Event data.  

<|ref|>text<|/ref|><|det|>[[115, 631, 710, 648]]<|/det|>
The Changed Namespace Event shall set the Persistent Event Log Event Header:  

<|ref|>text<|/ref|><|det|>[[143, 655, 420, 685]]<|/det|>
Event Type field to 06h; and Event Type Revision Field to 02h.
