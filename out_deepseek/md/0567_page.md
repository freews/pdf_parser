<|ref|>title<|/ref|><|det|>[[114, 513, 465, 525]]<|/det|>
# 8.1.6.2.2 Authenticated Unfreeze Operation

<|ref|>text<|/ref|><|det|>[[114, 538, 883, 580]]<|/det|>
This section describes how a host initiates an authenticated unfreeze operation using a Personality Unfreeze Request by submitting a Security Send command, and subsequently submitting a Security Receive command to retrieve the result of the Personality Unfreeze Request operation.

<|ref|>text<|/ref|><|det|>[[114, 589, 857, 601]]<|/det|>
The Security Send command contains a CDP Request Data Frame (refer to Figure 630) that specifies:

<|ref|>text<|/ref|><|det|>[[143, 612, 797, 625]]<|/det|>
·a CDP Request Message Type value of 01h (i.e., Personality Unfreeze Request); and

<|ref|>text<|/ref|><|det|>[[143, 628, 222, 638]]<|/det|>
·either:

<|ref|>text<|/ref|><|det|>[[203, 649, 883, 661]]<|/det|>
o CDP Programmable Key Authentication Unfreeze Data (refer to Figure 632) when using

<|ref|>text<|/ref|><|det|>[[203, 663, 775, 675]]<|/det|>
Programmable Key Authentication (refer to the AUS field in Figure 285); or

<|ref|>text<|/ref|><|det|>[[203, 678, 883, 704]]<|/det|>
o CDP Physical Credential Authentication Unfreeze Request Data (refer to Figure 634) when using Physical Credential Authentication.

<|ref|>text<|/ref|><|det|>[[114, 715, 883, 742]]<|/det|>
A controller performs steps such as the following to process a CDP Request Data Frame for an Authenticated Unfreeze Request operation using Physical Credential Authentication:

<|ref|>text<|/ref|><|det|>[[143, 752, 883, 764]]<|/det|>
1. The controller verifies that the specified credential matches the Physical Presence Indicator (PPI).

<|ref|>text<|/ref|><|det|>[[143, 766, 823, 778]]<|/det|>
2. If the PPI is successfully verified, then the Personality Unfreeze Request is authenticated.

<|ref|>text<|/ref|><|det|>[[143, 781, 687, 792]]<|/det|>
3. The personality for the specified Personality Identifier is then unfrozen.

<|ref|>text<|/ref|><|det|>[[114, 803, 883, 815]]<|/det|>
As part of an authenticated unfreeze operation for a host using Programmable Key Authentication, a host:

<|ref|>text<|/ref|><|det|>[[143, 826, 883, 853]]<|/det|>
·retrieves the random nonce using the Random Nonce Request operation as described in section 8.1.6.3.2; and

<|ref|>text<|/ref|><|det|>[[143, 857, 883, 869]]<|/det|>
·specifies the random nonce as part of a Personality Unfreeze Request operation (refer to 8.1.6.2.1).
