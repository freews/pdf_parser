<|ref|>text<|/ref|><|det|>[[114, 377, 882, 422]]<|/det|>
The DH- HMAC- CHAP_Access- Request PDU contains the parameters exchanged by the host and the controller during a DH- HMAC- CHAP authentication transaction. The responder is the entity that replied to a DH- HMAC- CHAP challenge sent by an authenticator.  

<|ref|>text<|/ref|><|det|>[[114, 427, 882, 458]]<|/det|>
Referring to Figure 812, when the controller transmits the DH- HMAC- CHAP_Access- Request PDU, the parameters are instantiated as follows:  

<|ref|>text<|/ref|><|det|>[[143, 465, 689, 560]]<|/det|>
- Responder's Role: 'H'- Sequence Number: S- Augmented Challenge Value: Ca- Response Value: R- NQNR: NQN- HashID, T_ID, SC_C: the correspondent DH-HMAC-CHAP parameters  

<|ref|>text<|/ref|><|det|>[[114, 564, 882, 595]]<|/det|>
When the host transmits the DH- HMAC- CHAP_Access- Request PDU, the parameters are instantiated as follows:  

<|ref|>text<|/ref|><|det|>[[143, 602, 689, 697]]<|/det|>
- Responder's Role: 'C'- Sequence Number: S- Augmented Challenge Value: Ca- Response Value: R- NQNR: NQN- HashID, T_ID, SC_C: the correspondent DH-HMAC-CHAP parameters  

<|ref|>text<|/ref|><|det|>[[114, 701, 882, 732]]<|/det|>
Upon receiving a DH- HMAC- CHAP_Access- Request PDU, the AVE shall perform the following steps in order:  

<|ref|>text<|/ref|><|det|>[[128, 737, 882, 884]]<|/det|>
1. Lookup the DH-HMAC-CHAP key of the responder (i.e., K) from NQNR; 
2. If the Responder's Role is 'H', compute the expected response R' as: \(\mathsf{R}^{\prime} = \mathsf{H M A C}(\mathsf{K r},\mathsf{C a}\parallel \mathsf{S}\parallel \mathsf{T}\_ \mathsf{I D}\parallel \mathsf{S C}\_ \mathsf{C}\parallel\) "HostHost" \(\parallel \mathsf{N Q N}\parallel \mathsf{00h}\parallel \mathsf{N Q N a})\) where NQNa is the NQN of the authenticator; 
3. If the Responder's Role is 'C', compute the expected response R' as: \(\mathsf{R}^{\prime} = \mathsf{H M A C}(\mathsf{K r},\mathsf{C a}\parallel \mathsf{S}\parallel \mathsf{T}\_ \mathsf{I D}\parallel \mathsf{S C}\_ \mathsf{C}\parallel\) "Controller" \(\parallel \mathsf{N Q N}\parallel \mathsf{00h}\parallel \mathsf{N Q N a})\) where NQNa is the NQN of the authenticator; and 
4. Compare the expected response R' with the response value R received in the DH-HMACCHAP_Access-Request PDU. If \(\mathsf{R}^{\prime} = \mathsf{R}\) then the authentication is successful; if \(\mathsf{R}^{\prime}\neq \mathsf{R}\) then the authentication has failed.
