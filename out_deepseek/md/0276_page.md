#### 5.2.12.1.14.2.7 Format NVM Start Event (Event Type 07h)  

<|ref|>text<|/ref|><|det|>[[114, 113, 883, 158]]<|/det|>
A Format NVM Start event shall be recorded in the Persistent Event Log after successfully validating the command parameters of a Format NVM command (refer to section 5.2.10) and before modifying any of the contents of the NVM.  

<|ref|>text<|/ref|><|det|>[[114, 164, 683, 180]]<|/det|>
The Format NVM Start event shall set the Persistent Event Log Event Header:  

<|ref|>text<|/ref|><|det|>[[143, 188, 415, 218]]<|/det|>
Event Type field to 07h; and Event Type Revision field to 01h.

#### 5.2.12.1.14.2.8 Format NVM Completion Event (Event Type 08h)  

<|ref|>text<|/ref|><|det|>[[114, 399, 883, 429]]<|/det|>
A Format NVM Completion event shall be recorded in the Persistent Event Log at the completion of a Format NVM command that resulted in modification of the contents of the NVM.  

<|ref|>text<|/ref|><|det|>[[114, 436, 731, 452]]<|/det|>
The Format NVM Completion event shall set the Persistent Event Log Event Header:  

<|ref|>text<|/ref|><|det|>[[143, 459, 415, 490]]<|/det|>
Event Type field to 08h; and Event Type Revision field to 02h.
