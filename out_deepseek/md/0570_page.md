#### 8.1.6.3.1.1 Key Derivation  

<|ref|>text<|/ref|><|det|>[[115, 563, 883, 595]]<|/det|>
The Derived HMAC Key (DHK) shall be derived by applying a secure keyed- hash function (refer to the CDPALG field in Figure 328) to:  

<|ref|>text<|/ref|><|det|>[[142, 600, 883, 648]]<|/det|>
the CDP Subsystem Unique String as defined in Figure 654; and the host- specified value of the key (i.e., the key specified in the Host Programmed Key field in the Security Send command payload),  

<|ref|>text<|/ref|><|det|>[[115, 653, 883, 684]]<|/det|>
as the inputs to the secure keyed- hash function. If an authentication method is supported (refer to the AUS field in Figure 285), then the FGUID field as defined in Figure 328 shall be supported.  

<|ref|>text<|/ref|><|det|>[[115, 689, 883, 720]]<|/det|>
The CDP Subsystem Unique String is shown in Figure 654. That string is used by the controller for deriving the DHK that is unique to the NVM subsystem.
