<|ref|>text<|/ref|><|det|>[[114, 128, 883, 185]]<|/det|>
Stream resources are the resources in the NVM subsystem that are necessary to track operations associated with a specified stream identifier. There are a maximum number of stream resources that are available in an NVM subsystem as indicated by the Max Stream Limit (MSL) field in the Return Parameters data structure (refer to Figure 655).

<|ref|>text<|/ref|><|det|>[[114, 194, 883, 236]]<|/det|>
Available NVM subsystem stream resources are stream resources that are not allocated for exclusive use in any namespace. Available NVM subsystem stream resources are reported in the NVM Subsystem Streams Available (NSSA) field (refer to Figure 655) and may be used by any host in any namespace that:

<|ref|>text<|/ref|><|det|>[[144, 245, 432, 258]]<|/det|>
· has the Streams Directive enabled;

<|ref|>text<|/ref|><|det|>[[144, 260, 883, 288]]<|/det|>
·has not been allocated exclusive stream resources by that host if the Shared Stream Identifiers (SSID) bit is cleared to '0' in the NSSC field; and

<|ref|>text<|/ref|><|det|>[[144, 290, 822, 303]]<|/det|>
·has not been allocated exclusive stream resources by any host if the SSID bit is set to '1'.

<|ref|>text<|/ref|><|det|>[[114, 312, 883, 339]]<|/det|>
Each time stream resources are allocated for exclusive use in a specified namespace, the available NVM subsystem stream resources reported in the NSSA field are reduced.

<|ref|>text<|/ref|><|det|>[[114, 349, 295, 362]]<|/det|>
For a given namespace:

<|ref|>text<|/ref|><|det|>[[144, 371, 883, 398]]<|/det|>
a) a host allocates stream resources to that namespace for the exclusive use of that host(s) by issuing the Allocate Resources operation;

<|ref|>text<|/ref|><|det|>[[144, 400, 883, 426]]<|/det|>
b) other hosts may concurrently allocate stream resources to that namespace for their exclusive use;and

<|ref|>text<|/ref|><|det|>[[144, 430, 883, 457]]<|/det|>
c) hosts which have not allocated stream resources to that namespace may use available NVM subsystem stream resources for access to that namespace.

<|ref|>text<|/ref|><|det|>[[114, 466, 883, 522]]<|/det|>
If an NVM subsystem has streams resources allocated to a host with a Host Identifier value of Oh and the Host Identifier is subsequently changed to a non-zero value, then those streams resources remain associated with the Host with a Host Identifier value of Oh and are not associated with the host with the non-zero Host Identifier.
