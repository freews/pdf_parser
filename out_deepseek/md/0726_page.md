#### 8.3.2.3.8.3.3 Remove Active ZoneGroup (RAZ)  

<|ref|>text<|/ref|><|det|>[[114, 603, 882, 706]]<|/det|>
The Remove Active ZoneGroup (RAZ) operation allows a DDC to remove from the CDC an active ZoneGroup associated with that DDC. For a pull model DDC the RAZ operation is mapped to a Pull Model DDC Request asynchronous event notification (refer to Figure 154). The CDC responds to that asynchronous event notification with a Get Log Page command requesting the Pull Model DDC Request log page (refer to section 5.2.12.3.6), to which the DDC responds with a log page requesting an RAZ operation for a specified ZoneGroup. The RAZ operation is then completed by the CDC by issuing one FZS command to provide an operation status to the DDC, as shown in Figure 770.
