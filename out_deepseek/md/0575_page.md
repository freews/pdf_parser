#### 8.1.8.2 Extended Device Self-Test Operation

<|ref|>text<|/ref|><|det|>[[113, 485, 883, 543]]<|/det|>
An extended device self-test operation should complete in the time indicated in the Extended Device Self-test Time field in the Identify Controller data structure or less. The percentage complete of the extended device self-test operation is indicated in the Current Percentage Complete field in the Device Self-test log page (refer to section 5.2.12.1.7).

<|ref|>text<|/ref|><|det|>[[113, 551, 883, 608]]<|/det|>
An extended device self-test operation shall persist across any Controller Level Reset and shall resume after completion of the reset or any restoration of power, if any. The segment where the extended device self-test operation resumes is vendor specific, but implementations should only have to perform tests again within the last segment that was being tested prior to the reset.

<|ref|>text<|/ref|><|det|>[[113, 618, 401, 630]]<|/det|>
An extended device self-test operation:

<|ref|>text<|/ref|><|det|>[[148, 639, 708, 652]]<|/det|>
a) shall be aborted by a Format NVM command as described in Figure 644;

<|ref|>text<|/ref|><|det|>[[148, 654, 737, 667]]<|/det|>
b) shall be aborted when a sanitize operation is started (refer to section 5.2.22);

<|ref|>text<|/ref|><|det|>[[148, 668, 883, 695]]<|/det|>
c) shall be aborted if a Device Self-test command with the Self-Test Code field set to Fh is processed;and

<|ref|>text<|/ref|><|det|>[[148, 698, 805, 711]]<|/det|>
d) may be aborted if the specified namespace is removed from the namespace inventory.

#### 8.1.9 Directives

<|ref|>text<|/ref|><|det|>[[113, 746, 883, 833]]<|/det|>
Directives is a mechanism to enable host and NVM subsystem or controller information exchange. The Directive Receive command (refer to section 5.2.6) is used to transfer data related to a specific Directive Type from the controller to the host. The Directive Send command (refer to section 5.2.7) is used to transfer data related to a specific Directive Type from the host to the controller. Other commands may include a Directive Specific value specific for a given Directive Type (e.g., the Write command in the NVM Command Set).

<|ref|>text<|/ref|><|det|>[[113, 841, 883, 870]]<|/det|>
Support for Directives is optional and is indicated by the Directives Supported (DIRS) bit in the Optional Admin Command Support (OACS) field in the Identify Controller data structure (refer to Figure 328).
