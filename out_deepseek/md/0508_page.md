#### 5.4.9.1.4 Revoke Host Access (Management Operation 04h)  

<|ref|>text<|/ref|><|det|>[[115, 204, 883, 268]]<|/det|>
The Revoke Host Access operation of the Manage Exported NVM Subsystem command is used to revoke access to the specified Exported NVM Subsystems from a list of specified hosts. The data pointer shall point to a Subsystem Management data structure (refer to Figure 557). The Management Operation Specific field in Command Dword 10 is reserved and not used by this operation.  

<|ref|>text<|/ref|><|det|>[[117, 274, 736, 291]]<|/det|>
The Revoke Host Access operation may be used to revoke 1 to N Hosts access from:  

<|ref|>text<|/ref|><|det|>[[142, 297, 883, 329]]<|/det|>
a specified Exported NVM Subsystem through 1 to M specified ports; or N different Exported NVM Subsystems through a specified port on each Exported NVM Subsystem.  

<|ref|>text<|/ref|><|det|>[[115, 335, 883, 382]]<|/det|>
Connected Hosts that have access revoked from a specified Exported NVM Subsystem on a specified Exported Port shall be disconnected from the specified Exported NVM Subsystem(s) on the specified Exported port.  

<|ref|>text<|/ref|><|det|>[[115, 389, 883, 436]]<|/det|>
Command specific status values associated with the Revoke Host Access operation of the Manage Exported NVM Subsystem command are defined in Figure 560. For failures, the byte offset of a failing entry shall be reported in the Command Specific Information field of the Error Information Log Entry.

#### 5.4.9.2 Command Completion  

<|ref|>text<|/ref|><|det|>[[115, 471, 883, 530]]<|/det|>
Upon completion of the Manage Exported NVM Subsystem command, the controller posts a completion queue entry to the Admin Completion Queue indicating the status for the command. Reference sections 5.4.9.1.1 through 5.4.9.1.4 for operation specific command completion details. Refer to section 8.3.4 for usages.  

<|ref|>title<|/ref|><|det|>[[115, 539, 432, 555]]<|/det|>
#### 5.4.10 Manage Exported Port command  

<|ref|>text<|/ref|><|det|>[[115, 563, 883, 609]]<|/det|>
The Manage Exported Port command is used to manage associations of Exported Ports with Exported NVM Subsystems. The Manage Exported Port command uses the Data Pointer and Command Dword 10. All other command specific fields are reserved.  

<|ref|>text<|/ref|><|det|>[[115, 615, 883, 660]]<|/det|>
The Select field defined in Figure 562 determines which management operation is to be performed in this command. The specified management operation determines the data structure used as part of the command. The data structure is 4,096 bytes in size.  

<|ref|>text<|/ref|><|det|>[[115, 666, 784, 682]]<|/det|>
The Manage Exported Port command shall not be supported by Exported NVM Subsystems.
