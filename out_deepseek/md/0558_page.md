#### 8.1.5 Command and Feature Lockdown  

<|ref|>text<|/ref|><|det|>[[115, 113, 883, 159]]<|/det|>
The Command and Feature Lockdown capability is used to prohibit the execution of commands submitted to NVM Express controllers and/or Management Endpoints in an NVM subsystem. Within this feature, commands and Feature Identifiers are defined with the following scopes:  

<|ref|>text<|/ref|><|det|>[[156, 165, 883, 257]]<|/det|>
Admin Command Set commands defined by the Opcode field; Set Features command features defined by the Feature Identifier field; Management Interface Command Set commands defined by the Opcode field (refer to the NVM Express Management Interface Specification); and PCle Command Set commands defined by the Opcode field (refer to the NVM Express Management Interface Specification).  

<|ref|>text<|/ref|><|det|>[[115, 263, 883, 308]]<|/det|>
Admin Command Set commands and Feature Identifiers are defined to be prohibitable by this feature, however it is vendor specific which of the Command Set commands and Feature Identifiers are prohibitable from execution, including the Lockdown command itself.  

<|ref|>text<|/ref|><|det|>[[115, 314, 883, 345]]<|/det|>
The prohibition of commands or Feature Identifiers on an interface is specified in the Interface field of the Lockdown command (refer to section 5.2.15). The prohibition applies to all applicable:  

<|ref|>text<|/ref|><|det|>[[156, 352, 406, 383]]<|/det|>
NVM Express controllers; and Management Endpoints,  

<|ref|>text<|/ref|><|det|>[[115, 388, 527, 404]]<|/det|>
in the NVM subsystem, as specified in the Interface field.  

<|ref|>text<|/ref|><|det|>[[115, 410, 883, 441]]<|/det|>
The Lockdown command is used to specify commands that are prohibited from execution (i.e., locked down) and may be used further to then again allow that command to be executed.  

<|ref|>text<|/ref|><|det|>[[115, 447, 713, 463]]<|/det|>
The prohibiting of execution of a command as part of this feature shall persist until:  

<|ref|>text<|/ref|><|det|>[[145, 469, 591, 499]]<|/det|>
a) power cycle of the NVM subsystem; or 
b) further being allowed by a follow-on Lockdown command.  

<|ref|>text<|/ref|><|det|>[[115, 505, 883, 551]]<|/det|>
If a controller in the NVM subsystem processes an Admin Command Set command or Feature Identifier that is prohibited from execution if received on an Admin submission queue, then that command shall be aborted with a status code of Command Prohibited by Command and Feature Lockdown.  

<|ref|>text<|/ref|><|det|>[[115, 556, 883, 602]]<|/det|>
If a Management Endpoint processes a command that is prohibited from execution on that Management Endpoint, then that command shall be aborted and a Response Message with an Access Denied Error Response (refer to the NVM Express Management Interface Specification) shall be returned.  

<|ref|>text<|/ref|><|det|>[[115, 608, 883, 683]]<|/det|>
The prohibition or allowance of the execution of a command is based on the interface on which the command is received (i.e., the Admin Submission Queue, or an out- of- band Management Endpoint). For example, a command is able to be prohibited if received on an Admin Submission Queue but allowed if received on an out- of- band Management Endpoint, if supported. The Interface field in the Lockdown command (refer to 5.2.15) is used to specify this behavior.  

<|ref|>text<|/ref|><|det|>[[115, 689, 883, 764]]<|/det|>
A host may use the Command and Feature Lockdown log page (refer to section 5.2.12.1.20) to determine the commands and Feature Identifiers that are allowed to be prohibited from execution. A Get Log Page command specifying the Command and Feature Lockdown log page returns a list of Admin command opcodes or Feature Identifiers depending on the scope specified in the Get Log Page command. The returned list of opcodes or Feature Identifiers are the opcodes or Feature Identifiers that are:  

<|ref|>text<|/ref|><|det|>[[143, 769, 804, 813]]<|/det|>
a) supported as being prohibitable from execution using the Lockdown command; 
b) currently prohibited from execution if received on an Admin Submission Queue; or 
c) currently prohibited from execution if received out-of-band on a Management Endpoint.  

<|ref|>text<|/ref|><|det|>[[115, 819, 883, 865]]<|/det|>
If the Command and Feature Lockdown capability is supported (i.e., the CFLS bit in the OACS field in Figure 328 is set to '1'), then the controller shall support the Lockdown command and the Command and Feature Lockdown log page.
