#### 5.1.1 NVM Subsystem Sanitize Operation and Format NVM Admin Command Processing Restrictions  

<|ref|>text<|/ref|><|det|>[[114, 154, 883, 199]]<|/det|>
Figure 143 lists the Admin commands that are allowed while an NVM subsystem sanitize operation is in progress and the Admin commands that should be allowed during the processing of a Format NVM command.  

<|ref|>text<|/ref|><|det|>[[114, 205, 883, 250]]<|/det|>
If a Format NVM command is in progress, then an Admin command not listed in Figure 143 that is submitted for any namespace affected by that Format NVM command may be aborted. If aborted for that reason, then a status code of Format In Progress should be returned.  

<|ref|>text<|/ref|><|det|>[[114, 256, 883, 302]]<|/det|>
If there are Admin commands not listed in Figure 143 being processed for a namespace, then a Format NVM command which is submitted that affects that namespace may be aborted. If aborted for that reason, then a status code of Command Sequence Error should be returned.
