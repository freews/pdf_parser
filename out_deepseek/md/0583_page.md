#### 8.1.9.3.1.1 Return Parameters (Directive Operation 01h)  

<|ref|>text<|/ref|><|det|>[[115, 217, 883, 278]]<|/det|>
The Return Parameter operation returns a data structure that specifies the features and capabilities supported by the Streams Directive, including namespace specific values. The DSPEC field in command Dword 11 is not used for this operation. The data structure returned is defined in Figure 655. If an NSID value of FFFFFFFFh is specified, then the controller:
