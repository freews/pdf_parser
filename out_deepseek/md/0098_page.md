#### 3.1.4.25 Offset E0Ch: PMREBS - Persistent Memory Region Elasticity Buffer Size  

<|ref|>text<|/ref|><|det|>[[115, 755, 883, 800]]<|/det|>
This optional property identifies to the host the size of the PMR elasticity buffer. A value of Oh in this property indicates to the host that no information regarding the presence or size of a PMR elasticity buffer is available.
