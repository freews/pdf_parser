<|ref|>title<|/ref|><|det|>[[137, 172, 421, 188]]<|/det|>
#### 8.1.26.4.5 Unrestricted Failure State  

<|ref|>text<|/ref|><|det|>[[117, 196, 833, 213]]<|/det|>
This state is entered if sanitize processing was performed in the Unrestricted Processing state and:  

<|ref|>text<|/ref|><|det|>[[142, 219, 883, 264]]<|/det|>
a) sanitize processing failed; or 
b) a failure occurred during deallocation of media in the sanitization target that is allocated for user data in the Post-Verification Deallocation state.  

<|ref|>text<|/ref|><|det|>[[114, 271, 206, 285]]<|/det|>
In this state:  

<|ref|>text<|/ref|><|det|>[[142, 291, 883, 325]]<|/det|>
a) all controllers and Management Endpoints in the NVM subsystem shall process commands as described in section 8.1.26.5;  

<|ref|>text<|/ref|><|det|>[[142, 323, 883, 367]]<|/det|>
b) all controllers in the NVM subsystem shall abort a Sanitize command or Sanitize Namespace command specifying the SANACT field set to 101b (i.e., Exit Media Verification State) with a status code of Invalid Field in Command;  

<|ref|>text<|/ref|><|det|>[[142, 366, 883, 425]]<|/det|>
c) if the sanitization target is the NVM subsystem, then all controllers in the NVM subsystem shall abort a Sanitize command, and a Sanitize Namespace command for the sanitization target associated with this state machine, that specifies the SANACT field set to a value that is not set to 101b (i.e., Exit Media Verification State) and that is set to a value other than:  

<|ref|>text<|/ref|><|det|>[[171, 431, 576, 494]]<|/det|>
001b (i.e., Exit Failure Mode); 010b (i.e., Start a Block Erase sanitize operation); 011b (i.e., Start an Overwrite sanitize operation); or 100b (i.e., Start a Crypto Erase sanitize operation),  

<|ref|>text<|/ref|><|det|>[[171, 500, 442, 515]]<|/det|>
with a status code of Sanitize Failed;  

<|ref|>text<|/ref|><|det|>[[142, 515, 883, 574]]<|/det|>
d) if the sanitization target is a namespace, then all controllers in the NVM subsystem shall abort a Sanitize command, and a Sanitize Namespace command for the sanitization target associated with this state machine, that specifies the SANACT field set to a value that is not set to 101b (i.e., Exit Media Verification State) and that is set to a value other than:  

<|ref|>text<|/ref|><|det|>[[171, 581, 574, 611]]<|/det|>
001b (i.e., Exit Failure Mode); or 100b (i.e., Start a Crypto Erase sanitize operation),  

<|ref|>text<|/ref|><|det|>[[171, 618, 568, 632]]<|/det|>
with a status code of Sanitize Namespace Failed; and  

<|ref|>text<|/ref|><|det|>[[142, 632, 730, 648]]<|/det|>
e) the Persistent Memory Region shall behave as described in section 8.1.26.5.
