#### 5.2.12.1.27 Changed Allocated Namespace List (Log Identifier 1Ch)  

<|ref|>text<|/ref|><|det|>[[115, 745, 883, 776]]<|/det|>
This log page is used to describe changes to allocated namespaces (refer to section 1.5.6), since the last time that this log page was read, that:  

<|ref|>text<|/ref|><|det|>[[142, 781, 860, 855]]<|/det|>
c) have changed information in their Identify Namespace data structures (refer to section 1.5.50);d) were previously unattached to the controller and have since been attached to the controller;e) were previously attached to the controller and have since been unattached from the controller;f) were created; andg) were deleted.  

<|ref|>text<|/ref|><|det|>[[115, 861, 883, 907]]<|/det|>
The log page contains a Namespace List with up to 1,024 entries. If more than 1,024 namespaces have changed attributes since the last time the log page was read, the first entry in the log page shall be set to FFFFFFFFh and the remainder of the list shall be zero filled.
