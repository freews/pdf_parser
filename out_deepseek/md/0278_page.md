#### 5.2.12.1.14.2.11 Set Feature Event (Event Type 0Bh)  

<|ref|>text<|/ref|><|det|>[[115, 240, 883, 271]]<|/det|>
The Set Feature Event persists the data of a successful Set Features command. The event contains a Persistent Event Log Event header and the Set Feature Event data (refer to Figure 250).  

<|ref|>text<|/ref|><|det|>[[115, 276, 638, 293]]<|/det|>
The Set Feature Event shall set the Persistent Event Log Event Header:  

<|ref|>text<|/ref|><|det|>[[143, 300, 420, 331]]<|/det|>
Event Type field to 0Bh; and Event Type Revision Field to 01h.  

<|ref|>text<|/ref|><|det|>[[115, 337, 852, 354]]<|/det|>
A Set Feature Event shall be recorded in the Persistent Event Log when the following criteria are met:  

<|ref|>text<|/ref|><|det|>[[143, 360, 884, 437]]<|/det|>
A Set Feature Event shall be recorded in the Persistent Event Log when the following criteria are met:- A Set Features command completes successfully;- The Feature Identifier in that Set Features command is supported to be logged in the Persistent Event Log; and- There is a change to the controller settings for the Feature Identifier in that Set Features command (i.e., the same setting is not set again).  

<|ref|>text<|/ref|><|det|>[[115, 441, 883, 473]]<|/det|>
A Set Feature Event may be recorded in the Persistent Event Log when there is no change to the controller settings for the Feature Identifier in that Set Features command if the following criteria are met:  

<|ref|>text<|/ref|><|det|>[[143, 480, 884, 526]]<|/det|>
A Set Features command completes successfully; and- The Feature Identifier in that Set Features command is supported to be logged in the Persistent Event Log.
