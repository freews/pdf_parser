#### 3.1.4.18 Offset 5Ch:CMBEBS-Controller Memory Buffer Elasticity Buffer Size  

<|ref|>text<|/ref|><|det|>[[114, 113, 883, 158]]<|/det|>
This optional property identifies to the host the size of the CMB elasticity buffer. A value of Oh in this property indicates to the host that no information regarding the presence or size of a CMB elasticity buffer is available.
