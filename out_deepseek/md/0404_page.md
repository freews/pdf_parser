#### 5.2.17.1 Migration Send Management Operations  

<|ref|>title<|/ref|><|det|>[[137, 114, 512, 130]]<|/det|>
#### 5.2.17.1.1 Suspend (Management Operation Oh)  

<|ref|>text<|/ref|><|det|>[[114, 138, 883, 169]]<|/det|>
The Suspend management operation of the Migration Send command allows a host to specify the type of suspend to be done on the specified controller.  

<|ref|>text<|/ref|><|det|>[[114, 175, 883, 206]]<|/det|>
The Suspend management operation uses the Command Dword 11 field as defined in Figure 367 and does not use the Management Operation Specific field.  

<|ref|>table<|/ref|><|det|>[[114, 241, 881, 472]]<|/det|>
<|ref|>table_caption<|/ref|><|det|>[[328, 218, 668, 234]]<|/det|>
Figure 367: Suspend - Command Dword 11   

<table><tr><td>Bits</td><td>Description</td></tr><tr><td>31</td><td>Delete User Data Migration Queue (DUDMQ): If this bit is set to &#x27;1&#x27; and the command completes successfully, then the User Data Migration Queue associated with the controller specified in the CNTLID field, if any, is deleted (refer to the applicable NVM Express I/O Command Set specification). If this bit is cleared to &#x27;0&#x27;, then the User Data Migration Queue associated the controller specified in the CNTLID field is retained after processing the command, if any.</td></tr><tr><td>30:24</td><td>Reserved</td></tr><tr><td colspan="2">Suspend Type (STYPE): This field specifies the type of suspend.</td></tr><tr><td>Value</td><td>Definition</td></tr><tr><td>23:16</td><td>Suspend Notification: The specified controller is going to be suspended in the future with a subsequent Migration Send command specifying a Suspend management operation and a non-zero value in the Suspend Type field.</td></tr><tr><td>1h</td><td>Suspend: Suspend the controller specified in the CNTLID field as defined in this section.</td></tr><tr><td>All Others</td><td>Reserved</td></tr><tr><td>15:00</td><td>Controller Identifier (CNTLID): This field specifies the identifier of the controller to which the Suspend management operation is performed.</td></tr></table>  

<|ref|>text<|/ref|><|det|>[[114, 483, 883, 543]]<|/det|>
A Suspend Type field value of Oh (i.e., Suspend Notification) allows a host to notify a controller that the controller specified by the Controller Identifier field is going to be requested to suspend with a subsequent Migration Send command specifying a Suspend management operation and a non- zero value in the Suspend Type field.  

<|ref|>text<|/ref|><|det|>[[114, 549, 883, 594]]<|/det|>
A Suspend Type field value of 1h (i.e., Suspend) specifies that the controller specified in the Controller Identifier field (refer to Figure 367) is to be suspended. That controller shall perform the following actions and then stop initiating transport transactions:  

<|ref|>text<|/ref|><|det|>[[148, 600, 883, 662]]<|/det|>
1. Stop fetching commands until the specified controller is no longer suspended (refer to section 8.1.13). 
2. Complete the processing of all previously fetched commands, if any, except any outstanding Asynchronous Event Request commands.  

<|ref|>text<|/ref|><|det|>[[114, 668, 131, 680]]<|/det|>
If:  

<|ref|>text<|/ref|><|det|>[[148, 689, 744, 720]]<|/det|>
the command causes the specified controller to be suspended; and there is a User Data Migration Queue associated with that specified controller,  

<|ref|>text<|/ref|><|det|>[[114, 728, 154, 741]]<|/det|>
then:  

<|ref|>text<|/ref|><|det|>[[148, 750, 883, 853]]<|/det|>
If the DUDMQ bit is set to '1', then the controller processing the command before posting the completion queue entry to the command shall delete that User Data Migration Queue; and after the specified controller completes the processing of all previously fetched commands, if any, except any outstanding Asynchronous Event Request commands, the controller processing the Migration Send command shall, at a vendor specific amount of time, posts an entry in that User Data Migration Queue that indicates the specified controller is suspended as specified by the applicable NVM Express I/O Command Set specification.  

<|ref|>text<|/ref|><|det|>[[114, 860, 883, 890]]<|/det|>
It is not an error if a suspend operation occurs on a controller that is already suspended with the same Suspend Type value.
