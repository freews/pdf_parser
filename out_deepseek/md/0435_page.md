#### 5.2.26.1.10 Non-Operational Power State Config (Feature Identifier 11h)  

<|ref|>text<|/ref|><|det|>[[114, 113, 883, 143]]<|/det|>
This Feature configures non- operational power state settings for the controller. The settings are specified in Command Dword 11.  

<|ref|>text<|/ref|><|det|>[[114, 149, 883, 180]]<|/det|>
If a Get Features command is submitted for this Feature, the values in Figure 418 are returned in Dword 0 of the completion queue entry for that command.  

<|ref|>table<|/ref|><|det|>[[114, 218, 881, 455]]<|/det|>
<|ref|>table_caption<|/ref|><|det|>[[220, 193, 773, 210]]<|/det|>
Figure 418: Non-Operational Power State Config - Command Dword 11   

<table><tr><td>Bits</td><td>Description</td></tr><tr><td>31:01</td><td>Reserved</td></tr><tr><td>00</td><td>Non-Operational Power State Permissive Mode Enable (NOPPME): If this bit is set to &#x27;1&#x27;, then the controller may temporarily exceed the power limits of any non-operational power state, up to the limits of the last operational power state, to run controller-initiated background operations in that state (i.e., Non-Operational Power State Permissive Mode is enabled). If this bit is cleared to &#x27;0&#x27;, then the controller shall not exceed the limits of any non-operational state while running controller-initiated background operations in that state (i.e., Non-Operational Power State Permissive Mode is disabled).<br>If Non-Operational Power State Permissive Mode is disabled, then:<br>a) thermal management that requires power (e.g., cooling fans) may be disabled; and<br>b) performance after resuming from the non-operational power state may be degraded until background activity that was not allowed while in that non-operational power state has completed.<br>If the host attempts to set this bit to &#x27;1&#x27; and the controller does not support Non-Operational Power State Permissive Mode as indicated in the Controller Attributes (CTRATT) field of the Identity Controller data structure, then the controller shall abort the command with a status code of Invalid Field in Command.</td></tr></table>

#### 5.2.26.1.11 Read Recovery Level Config (Feature Identifier 12h)  

<|ref|>text<|/ref|><|det|>[[114, 531, 883, 576]]<|/det|>
This Feature is used to configure the Read Recovery Level (refer to section 8.1.22). The attributes are specified in Command Dword 11 and Command Dword 12. Modifying the Read Recovery Level has no effect on the data contained in any associated namespace.  

<|ref|>text<|/ref|><|det|>[[115, 583, 324, 598]]<|/det|>
The scope of this Feature is:  

<|ref|>text<|/ref|><|det|>[[143, 605, 525, 636]]<|/det|>
NVM Set if NVM Sets are supported; or NVM Subsystem if NVM Sets are not supported.  

<|ref|>text<|/ref|><|det|>[[114, 642, 883, 673]]<|/det|>
If a Get Features command is submitted for this Feature, the attributes specified in Figure 420 are returned in Dword 0 of the completion queue entry for that command.
