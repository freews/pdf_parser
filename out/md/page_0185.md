- **NVMe Logical Blocks** range from **LBA x** to **LBA x+26**.
- The logical blocks are divided into segments:
  - **3KiB** → transferred to **Data Block A** in Host DRAM.
  - **4KiB** → transferred to **Data Block C** in Host DRAM.
  - **2KiB** → marked as **Bit Bucket data not transferred**.
  - **4KiB** → transferred to **Data Block B** in Host DRAM.

**Destination SGL Segment 0**:
- **Address = A**
  - Descriptor 0: **Length = 3KiB** → corresponds to Data Block A.
  - Descriptor 2: **Length = 48** → points to next segment (Segment 1).

**Destination SGL Segment 1**:
- **Address = B**
  - Descriptor 0: **Length = 4KiB** → corresponds to Data Block B.
  - Descriptor 1: **Length = 2KiB** → Bit Bucket (data not transferred).
  - Descriptor 3: **Length = 16** → points to next segment (Segment 2).

**Destination SGL Segment 2**:
- **Address = C**
  - Descriptor 0: **Length = 4KiB** → corresponds to Data Block C.

Annotations:
- **SGL Data Block descriptor** specifies transfer of 3KiB → points to Descriptor 0 in Segment 0.
- **Segment descriptor** points to next memory location in SGL → Descriptor 2 in Segment 0 points to Segment 1.
- **Data Block descriptor** specifies transfer of 4KiB → points to Descriptor 0 in Segment 1.
- **Bit Bucket descriptor** specifies not to transfer next 2KiB → Descriptor 1 in Segment 1.
- **Last Segment descriptor** points to last memory location in SGL → Descriptor 3 in Segment 1 points to Segment 2.
- **Data Block descriptor** specifies transfer of 4KiB → points to Descriptor 0 in Segment 2.

### 4.4 Feature Values

The Get Features command (refer to section 5.2.11) and Set Features command (refer to section 5.2.26) may be used to read and modify operating parameters of the controller. The operating parameters are grouped and identified by Feature Identifiers. Each Feature Identifier contains one or more attributes that may affect the behavior of the Feature.
