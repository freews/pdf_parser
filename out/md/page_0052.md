NVM Express® Base Specification, Revision 2.3

**Figure 13: Simple NVM Storage Hierarchy with Multiple Reclaim Groups**

<!-- Figure 13, coordinate:(158,122,808,440) -->

The diagram shows a hierarchical structure:

- Outermost box: **NVM Subsystem**
- Inside: **Domain 0** (light green background)
- Inside Domain 0: **Endurance Group 1** (light peach background)
- Inside Endurance Group 1: Four **Reclaim Groups** (Reclaim Group 0, 1, 2, 3) — each represented as a light blue rectangle.
- A horizontal white rectangle labeled **Namespace 1** spans across the four Reclaim Groups, indicating it is composed of resources from all of them.

Figure 14 shows the relationships of these entities in a complex NVM subsystem, which has:
- multiple domains;
- multiple Endurance Groups per domain;
- multiple NVM Sets per Endurance Group; and
- multiple namespaces per NVM Set.
