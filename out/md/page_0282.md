### 5.2.12.1.14.2.14 Sanitize Media Verification Event (Event Type 0Eh)

A Sanitize Media Verification event shall be recorded in the Persistent Event log page upon transition to the Media Verification state (refer to section 8.1.26.4.6).

No Event Data (refer to Figure 231) is defined for this event.

The Sanitize Media Verification event shall set the Persistent Event Log Event Header:
- Event Type field to 0Eh;
- Event Type Revision field to 01h; and
- Event Length field to 0h.
