Upon successful completion of a Manage Exported Port command with a Delete operation the specified Exported Port ID has been removed from the specified Exported NVM Subsystem.

### 5.4.10.2 Command Completion

Upon completion of the Manage Exported Port command, the controller posts a completion queue entry to the Admin Completion queue indicating the status of the command. Refer to section 8.3.4 for usages.

### 5.4.11 Send Discovery Log Page command

The Send Discovery Log Page (SDLP) command is used by a CDC to send a discovery log page to a pull model DDC. This command uses the Data Pointer, Command Dword 10, Command Dword 11, Command Dword 12, and Command Dword 13, as shown in Figure 567, Figure 568, Figure 569, Figure 570, and Figure 571 respectively.

#### Figure 567: Send Discovery Log Page (SDLP) – Data Pointer

| Bits | Description |
|------|-------------|
| 127:00 | **Data Pointer (DPTR)**: This field specifies the start of the data buffer. Refer to Figure 92 for the definition of this field. |

#### Figure 568: Send Discovery Log Page (SDLP) – Command Dword 10

| Bits | Description |
|------|-------------|
| 31:30 | **Requested Log Page Status (RLPS)**: This field specifies the status of the requested log page. Defined values are: |
|      | <table><tr><th>Value</th><th>Definition</th></tr><tr><td>00b</td><td><strong>Valid Log Page</strong>: the requested log page is carried in the command.</td></tr><tr><td>01b</td><td><strong>Invalid Log Page</strong>: The requested log page is invalid or not supported.</td></tr><tr><td>10b</td><td><strong>Not Allowed Log Page</strong>: The requested log page is not allowed to be transferred by an SDLP command (refer to Figure 572).</td></tr><tr><td>11b</td><td><strong>Not Successful</strong>: Retrieving the requested log page failed. Further details are provided in the SCT field and the SC field.</td></tr></table> |
| 29:28 | Reserved |
| 27:25 | **Status Code Type (SCT)**: Refer to Figure 100. |
| 24:17 | **Status Code (SC)**: Refer to Figure 100. |
| 16:15 | Reserved |
| 14:08 | **Transferred Log Specific Parameter (TLSP)**: If not defined for the log page specified by the Log Page Identifier field, this field is reserved. |
| 07:00 | **Transferred Log Page Identifier (TLID)**: This field specifies the identifier of the sent log page. |

#### Figure 569: Send Discovery Log Page (SDLP) – Command Dword 11

| Bits | Description |
|------|-------------|
| 31:00 | **Number of Dwords (NDWS)**: This field specifies the number of transferred dwords. |

#### Figure 570: Send Discovery Log Page (SDLP) – Command Dword 12

| Bits | Description |
|------|-------------|
| 31:00 | **Transferred Log Page Offset Lower (TLPOL)**: This field specifies the least-significant 32 bits of the offset of the transferred log page. |

#### Figure 571: Send Discovery Log Page (SDLP) – Command Dword 13

| Bits | Description |
|------|-------------|
| 31:00 | **Transferred Log Page Offset Upper (TLPOU)**: This field specifies the most-significant 32 bits of the offset of the transferred log page. |
