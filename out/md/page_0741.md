**Figure 785: Unique Discovery Service NQN retrieval for bidirectional authentication**

The diagram illustrates a sequence of interactions between "Host Functionality (Host or CDC)" and "Discovery Controller (DC)" for retrieving a unique Discovery Service NQN and establishing bidirectional authentication.

**Sequence Steps:**

1. **Transport connection established**  
   - Host sends: `Connect (SUBNQN = well-known DS NQN)`  
   - DC responds: `Response (AUTHREQ = 1)`

2. **Unidirectional authentication**  
   - Host sends: `AUTH_Negotiate`  
   - DC sends: `DH-HMAC-CHAP_Challenge`  
   - Host sends: `DH-HMAC-CHAP_Reply`  
   - DC sends: `DH-HMAC-CHAP_Success1`  
   - *Note: DC authenticates host. Host does not authenticate DC since it is only aware of the well-known Discovery service NQN.*

3. **Controller Initialization**

4. **Identify (CNS 01h)**  
   - Host sends: `Identify (CNS 01h)`  
   - DC responds: `Response (Unique DS NQN)`

5. **Controller Shutdown**  
   - Transport connection terminated  
   - Transport connection established (new session)

6. **Connect (SUBNQN = Unique DS NQN)**  
   - Host sends: `Connect (SUBNQN = Unique DS NQN)`  
   - DC responds: `Response (AUTHREQ = 1)`

7. **Bidirectional authentication**  
   - Host sends: `AUTH_Negotiate`  
   - DC sends: `DH-HMAC-CHAP_Challenge`  
   - Host sends: `DH-HMAC-CHAP_Reply`  
   - DC sends: `DH-HMAC-CHAP_Success1`  
   - Host sends: `DH-HMAC-CHAP_Success2`  
   - *Note: DC authenticates host. Host authenticates DC using unique Discovery service NQN discovered above.*

### 8.3.5.2.2 NVMe In-band Authentication Protocol-Specific Requirements

Authentication requirements for security commands are based on the security protocol indicated by the SECP field in the command.

The authentication protocols defined by this specification use the security protocol identifier **E9h** (assigned to NVMe by SPC-5, a SCSI standard). The messages of the defined authentication protocols are self-identifying; therefore, the **SPSP0** field and the **SPSP1** field of the Authentication Send and Authentication Receive commands shall be set to **01h**. Authentication messages are mapped to NVMe over Fabrics command and response pairs. The mapping of authentication messages to the Authentication Send command is shown in Figure 786.

| SPSP1       | 01h    |
