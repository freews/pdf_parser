| 14 | M | **Namespace Status (NSTAT):** This field indicates the status of the namespace with the specified NSID. <br><br> **Bits Description** <br> 7:3 Reserved <br> <br> **I/O Impacted (IOI):** This field indicates whether I/O performance is currently degraded (e.g., I/O command processing is delayed or slow). <br><br> **Value Definition** <br> 00b I/O performance degradation is not reported <br> 01b Reserved <br> 10b I/O performance is not currently degraded <br> 11b I/O performance is currently degraded <br><br> **Namespace Ready (NRDY):** A value of ‘1’ indicates that the namespace is ready (refer to section 3.5.3). If this bit is cleared to ‘0’, then the Key Per I/O capability is not supported by the namespace. <br><br> **Key Per I/O Enabled in Namespace (KPIOENS):** If this bit is set to ‘1’, then the Key Per I/O capability is enabled on the namespace. The mechanism to enable the Key Per I/O capability on the namespace is outside the scope of this specification (refer to section 8.1.14). If this bit is cleared to ‘0’, then the Key Per I/O capability is disabled on the namespace. <br><br> *If the KPIOSNS bit is cleared to ‘0’, then this bit shall be cleared to ‘0’.* | Yes |
