**Figure 660: Data Replication Example 1**

The diagram shows two hosts, Host 1 and Host 2, each connected to an NVM Subsystem (NVM Subsystem 1 and NVM Subsystem 2, respectively). Each subsystem contains NVMe Controller(s) with associated NSIDs and namespaces (NS A in Subsystem 1, NS C in Subsystem 2). Both subsystems are connected to a shared namespace, NS B, via orange lines. Green arrows indicate communication between hosts and their respective subsystems.

Figure 661 shows another example of single NVM subsystem host connectivity, where two hosts access the same dispersed namespace being replicated across two participating NVM subsystems via controllers in only one NVM subsystem, but the host connected to NVM Subsystem 2 only accesses namespace B in the event of a failure scenario.

<!-- Figure 661: Data Replication Example 2, coordinate:(295,500,700,816) -->
**Figure 661: Data Replication Example 2**

This diagram is similar to Figure 660 but with a key difference: Host 2 is shown with a dashed green arrow to its NVMe Controller(s), indicating a non-active or failover connection. Host 1 remains actively connected (solid green arrow). Both NVM Subsystems 1 and 2 are connected to the shared namespace NS B. The namespaces within each subsystem are NS A (Subsystem 1) and NS C (Subsystem 2).

Figure 662 shows an example of multiple NVM subsystem host connectivity, where two hosts access the same dispersed namespace being replicated across two participating NVM subsystem via controllers in both NVM subsystems.
