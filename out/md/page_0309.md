<h3>5.2.12.1.31 Flexible Data Placement (FDP) Statistics (Log Page Identifier 22h)</h3>

<p>The FDP Statistics log page (refer to Figure 293) is used to provide information about the FDP configuration over the life of the FDP configuration in an Endurance Group. The Endurance Group is specified by the Endurance Group Identifier field in the Log Specific Identifier field as defined in Figure 221).</p>

<p>If Flexible Data Placement is enabled in the specified Endurance Group and the Get Log Page command specifies this log page, then the NSID field in that command is reserved.</p>

<p>If Flexible Data Placement is disabled in the specified Endurance Group and the Get Log Page command specifies this log page, then the controller shall abort the command with a status code of FDP Disabled.</p>
